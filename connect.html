Connecting to QuickBooks Online

Merchant First Reconciliation

Merchant First Reconciliation is an internal accounting tool of Merchant First LLC. It is installed and run on company-managed computers by employees and engaged professionals of Merchant First and its affiliated entities. It is not distributed publicly and has no customer sign-up.

How a company file is connected

An authorized user runs the application's connect command on the computer where the application is installed. The application opens Intuit's own authorization page in the user's browser. The user signs in to QuickBooks Online there — the application never sees the username or password — and selects the company file to authorize.

Intuit returns an authorization code to the application, which exchanges it for access and refresh tokens. Those tokens are stored in a file on that computer, readable only by that user account. Each company file is connected separately.

What access is granted

Read access under the com.intuit.quickbooks.accounting scope, used to retrieve the chart of accounts and bank transaction detail. The application does not create, modify or delete anything in QuickBooks Online.

Reconnecting

If a connection lapses — because the refresh token expired, access was revoked, or the token file was removed — the same connect command is run again and the authorization is repeated.
