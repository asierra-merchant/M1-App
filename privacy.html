Privacy Policy

Merchant First Reconciliation · Effective [9/25/26]

This Privacy Policy describes how the Merchant First Reconciliation software application (the "Software"), operated by Merchant First LLC ("Merchant First", "we"), handles information. The Software is an internal accounting tool used only by Merchant First and its affiliated entities on their own books. It is not offered to the public and has no users outside that group.

1. What the Software accesses

When connected to a QuickBooks Online company file, the Software reads, under the com.intuit.quickbooks.accounting scope:

  • the company's name and identifier;
  • the chart of accounts, limited to accounts of type Bank;
  • transaction detail for those accounts — date, type, reference number, payee or name, description, account, split account and amount.

The Software reads only. It does not create, modify or delete any record in QuickBooks Online.

The Software also reads bank statement PDFs and bank transaction exports that a user places in a folder on their own computer. Those files are supplied by the user; the Software does not retrieve them from any bank.

2. Why

Solely to prepare monthly bank reconciliation workpapers — comparing the balance recorded in QuickBooks Online against the balance reported by the bank and listing the differences. The data is used for no other purpose.

3. Where the data goes

Nowhere but the user's own computer. The Software runs locally. It has no server, no hosted component and no database of our own. Data retrieved from QuickBooks Online travels directly from Intuit's API to the computer running the Software, where it is written to files in a folder the user chooses.

We do not sell, rent, share, transfer or disclose this data to any third party. We do not use it for advertising, marketing, analytics, profiling, training of machine learning models, or any secondary purpose. The Software contains no analytics, telemetry, crash reporting or tracking of any kind.

The Software makes network connections to Intuit's authorization and API endpoints and to no other host.

4. Credentials and tokens

Authorization is performed through Intuit's OAuth 2.0 flow. The Software never sees or stores a QuickBooks Online username or password; those are entered on Intuit's own sign-in page. The resulting access and refresh tokens, and the application's client credentials, are stored in files on the user's computer with access restricted to that user account, and are excluded from source control. They are used only to authenticate calls to Intuit's API.

5. Retention and deletion

Workpapers and the files they were built from are retained as accounting records of Merchant First, under the same records-retention and access policies that apply to the underlying bank statements and books. A user may delete the stored token file at any time, and may revoke the Software's access from within QuickBooks Online (Settings → Apps → Disconnect), which invalidates the tokens immediately.

6. Personal information

The Software is not designed to collect personal information and collects none directly from any individual. Transaction records retrieved from QuickBooks Online may incidentally contain the names of payees, which may include individuals. Such information is handled as part of the entities' accounting records, is stored only on company-controlled computers, and is not disclosed to any third party.

7. Security

All communication with Intuit is over TLS. Data at rest resides on company-controlled computers subject to Merchant First's existing access controls. No system can be guaranteed secure, and we make no warranty to that effect.

8. Children

The Software is a business accounting tool. It is not directed at children and is not used by anyone under 18.
